# Frua — Інтернет-магазин фруктів у шоколаді

Сайт створено для практичної роботи №2.

## Проект

Естетичний інтернет-магазин десертів ручної роботи «Frua».

### Функціонал
- Адаптивний дизайн
- Каталог товарів (12+ позицій)
- Сортування за ціною
- Кошик з додаванням товарів
- Hero-секція та основні сторінки

### Технології
- HTML5 + CSS3
- Tailwind CSS (через CDN)
- Vanilla JavaScript

### Як запустити
1. Завантажте репозиторій
2. Відкрийте index.html у браузері
